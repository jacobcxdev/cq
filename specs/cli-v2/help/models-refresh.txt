Refresh model sources and publish client model caches.

Usage: cq models refresh [OPTIONS]

Merge native provider data with local overlays, validate routing ownership, and publish
Codex model cache and available Claude Code capability and picker caches.

Use the running proxy registry refresh endpoint when healthy; otherwise refresh locally.
A reachable proxy error is reported rather than silently retried through a different
owner.

No overall command deadline is imposed. Individual request and phase deadlines are
listed below; interactive prompts can wait until input or interruption.

Proxy refresh has a fixed 5-second context deadline. Local registry source refresh has a
fixed 30-second phase deadline, and its HTTP client has a fixed 30-second per-request
timeout. The legacy health probe, when needed, has a fixed 2-second timeout. File
publication and pruning have no separate deadline.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq models refresh
      Refresh model data and publish caches.
  cq models refresh --json
      Report source and publication results as JSON.
