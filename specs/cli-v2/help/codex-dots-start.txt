Start Dots in the configured native app.

Usage: cq codex dots start [OPTIONS]

Start Dots in the configured native app.

Start the configured Dots adapter and check the native catalogue and workspace.

If the normal app must restart or a Dot needs onboarding, the result explains what
remains.

Options:
  --root ABS_PATH
      Private Dots installation directory (default ~/.local/share/cq/dots). Accept
      before or after the leaf command. This is not a global CQ option.
      Type: path. Required: false. Repeatable: false.
      Default: null.
      When omitted: Resolve ~/.local/share/cq/dots from the current user home after
      syntax validation.
      Constraint: Must be a clean absolute path when supplied.
      Constraint: Must not contain the home directory or overlap native app, credential
      or application-support paths.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq codex dots start
      Start Dots in the configured native app.
