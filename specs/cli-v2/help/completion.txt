Print a shell completion script.

Usage: cq completion SHELL [OPTIONS]

Print a completion script for Bash, Zsh or Fish to standard output. Source or install it
yourself. Completion lists public command names, options and fixed enum choices; it
never accesses credentials, accounts, network or proxy state.

Arguments:
  SHELL
      Shell to generate for: bash, zsh, fish.
      Type: enum. Required: true. Repeatable: false.
      Default: null.
      Choices: bash, zsh, fish.
      Constraint: Exact lowercase enum.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq completion zsh > "$HOME/.cq-completion.zsh"
      Write the generated script to a user-chosen file; source it in Zsh startup configuration.
