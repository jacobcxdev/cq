Usage: cq proxy <COMMAND> [OPTIONS]

Run and inspect the shared proxy, state and lifecycle machinery.

Choose a subcommand below. A bare group prints this help without reading configuration
or changing state.

Commands:
  proxy
      Run and inspect the shared proxy, state and lifecycle machinery.
  candidate
      Manage isolated candidate state and inspect release evidence.
  health
      Probe proxy HTTP liveness.
  operation
      Inspect retained shared proxy lifecycle operation state.
  rescue
      Inspect or transition the shared runtime rescue-serving mode.
  serve
      Run the shared API proxy in the foreground.
  state
      Initialise an explicitly selected shared proxy authority directory.
  status
      Inspect shared proxy readiness evidence.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq proxy --help
      Show all immediate subcommands and usage.
