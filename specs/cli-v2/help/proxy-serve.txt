Run the shared API proxy in the foreground.

Usage: cq proxy serve [OPTIONS]

Serve Claude and Codex requests on the configured loopback port until interrupted. This
starts no operating-system service.

A live port override applies to this process only. Existing clients are unaffected until
they connect to this listener.

Options:
  --port PORT
      Loopback listen port, 1–65535. Omit to use proxy.json port, or 19280 if absent.
      Type: integer. Required: false. Repeatable: false.
      Default: null.
      Constraint: No ephemeral port 0; reject a listener owned by another process.
  --migrate-legacy-managed
      Add missing routing identity metadata to legacy CQ-managed credentials before
      serving. Default: false.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Never changes external or system-owned credentials.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq proxy serve
      Run on configured port.
  cq proxy serve --port 29280
      Run an isolated listener on port 29280; choose config deliberately before supplying real traffic.
