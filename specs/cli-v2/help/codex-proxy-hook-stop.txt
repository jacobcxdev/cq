Return a private-data-safe routing receipt for a Codex Stop hook.

Usage: cq codex proxy hook stop [OPTIONS]

Machine integration: read exactly one Codex Stop event JSON object from standard input
and look up its turn receipt through authenticated loopback control.

Default output follows the Codex hook protocol: {} when absent, or
{"systemMessage":"..."} when found. With --json, wrap that same object in the canonical
CQ envelope for manual inspection; do not use --json in Codex hook configuration.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  printf '%s\n' '{"hook_event_name":"Stop","session_id":"s1","turn_id":"u1"}' | cq codex proxy hook stop
      Look up a synthetic event; an unknown turn returns {}.
