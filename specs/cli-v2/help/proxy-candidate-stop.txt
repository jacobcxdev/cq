Stop an isolated candidate after its client has stopped.

Usage: cq proxy candidate stop --state-dir STATE_DIR --confirm-client-stopped [OPTIONS]

Confirm every client using this candidate has stopped before stopping its runtime.
Confirmation is mandatory in both human and JSON modes.

A validated candidate can still be running; stop accepts that phase and verifies process
absence.

The deadline is fixed at 30 seconds, including a 15-second cleanup reserve; there is no
timeout option.

Options:
  --state-dir STATE_DIR
      Candidate state directory created by prepare. Required; absolute, clean, current-
      user-owned path. Never defaults to shared proxy state.
      Type: path. Required: true. Repeatable: false.
      Default: null.
      Constraint: Absolute, lexically clean path; not /; no symbolic link; owned by
      current user; parent owner-controlled.
  --confirm-client-stopped
      Assert that every client using this candidate has stopped and no request remains
      active. Required; must be true.
      Type: boolean. Required: true. Repeatable: false.
      Default: false.
      Constraint: Must be true.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq proxy candidate stop --state-dir "$CANDIDATE" --confirm-client-stopped
      Uses inputs prepared in the candidate workflow in the versioned annex notes.
