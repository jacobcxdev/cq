Manage multi-account Dots and their private installation state.

Usage: cq codex dots <COMMAND> [OPTIONS]

Manage multi-account Dots for the configured native app or an isolated research profile.

Choose a subcommand below. A bare group prints this help without reading configuration
or changing state.

--root is inherited by every Dots command and can appear before or after the leaf
command.

Commands:
  board
      Show or assign one local chat as the shared Dot message board.
  broadcast
      Send a user message to every discovered Dot.
  install
      Install multi-account Dots for the normal native app.
  list
      List discovered Dots.
  prime
      Prime one Dot or all discovered Dots.
  start
      Start Dots in the configured native app.
  status
      Show Dots status.
  stop
      Stop the Dots adapter after quitting the app.
  sync
      Refresh Dots account discovery.

Options:
  --root ABS_PATH
      Private Dots installation directory (default ~/.local/share/cq/dots). Accept
      before or after the leaf command. This is not a global CQ option.
      Type: path. Required: false. Repeatable: false.
      Default: null.
      When omitted: Resolve ~/.local/share/cq/dots from the current user home after
      syntax validation.
      Constraint: Must be a clean absolute path when supplied.
      Constraint: Must not contain the home directory or overlap native app, credential
      or application-support paths.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq codex dots --help
      Show Dots commands and inherited options.
