Inspect the legacy Codex credential socket and migration state.

Usage: cq codex proxy credential-endpoint legacy inspect [OPTIONS]

Maintain the local Codex credential-owner Unix socket, not the HTTP listener. Legacy
means a refused socket whose exact filesystem identity must be preserved during
migration.

Options:
  --timeout TIMEOUT
      Total deadline, including cleanup. Default: 30s. Allowed: 1s..5m inclusive; 0s
      reserved for cleanup.
      Type: duration. Required: false. Repeatable: false.
      Default: "30s".
      Constraint: Go duration syntax; 1s <= value <= 5m; cleanup reserve 0s; deadline
      cancellation must not leave an unrecorded mutation.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq codex proxy credential-endpoint legacy inspect
      Uses exact inspected snapshot or prepared ticket, as described in endpoint workflow notes.
