List active models from local registry caches.

Usage: cq models list [OPTIONS]

Reads cached native entries and local overlays without fetching providers. An empty
cache produces an empty list; run cq models refresh to populate it.

Provider names are claude and codex; claude identifies the Anthropic API route.

No overall command deadline is imposed. Individual request and phase deadlines are
listed below; interactive prompts can wait until input or interruption.

This command performs local reads only and has no HTTP request timeout.

Options:
  --provider PROVIDER
      Filter by claude or codex. Omitted: list both providers. Legacy anthropic means
      claude.
      Type: enum. Required: false. Repeatable: false.
      Default: null.
      Choices: claude, codex.
      Constraint: Reject other values; translate legacy anthropic to claude with
      deprecation warning.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq models list
      List cached models for both providers.
  cq models list --provider claude --json
      List Claude models as structured JSON.
