Inspect selected CQ service components.

Usage: cq service status [OPTIONS]

CQ services comprise the shared API proxy and a token-refresh job. The token-refresh job
runs auth refresh at load and every 30 minutes; it does not fetch quota reports.

Supported service managers: launchd on macOS, per-user systemd on Linux, and current-
user Task Scheduler on Windows. Unsupported environments fail explicitly before
mutation.

Options:
  --component COMPONENT
      Service component: all, proxy, or token-refresh. Default: all.
      Type: enum. Required: false. Repeatable: false.
      Default: "all".
      Choices: all, proxy, token-refresh.
      Constraint: Exact enum; selection never widens after validation.
  --strict
      Return non-zero if selected components are not installed, not running, or
      unhealthy. Default: false.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
  --timeout DURATION
      Maximum elapsed time, including locks, requests and local verification. Default:
      10s.
      Type: duration. Required: false. Repeatable: false.
      Default: "10s".
      Constraint: Positive Go duration, at most 10m; no bare number. Deadline expiry
      never implies rollback succeeded.

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq service status --component proxy
      Apply only to the shared proxy.
  cq service status --component token-refresh
      Apply only to the scheduled token-refresh component.
