Authenticate and store a Codex account.

Usage: cq codex account login [OPTIONS]

Open the Codex browser OAuth flow and save the authenticated account in CQ-managed local
storage. Login alone does not change the native client default account.

Use --activate to select the authenticated account as the native client default after
credentials are saved. Existing clients may need reconnection. Proxy pins and session
bindings do not change.

No refresh agent or proxy service is installed implicitly. JSON mode suppresses terminal
prompts; browser authentication still requires the user to complete the provider flow.

Options:
  --activate
      Make this account the native client default after successful login (default
      false). Existing clients may need reconnection.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
  --timeout DURATION
      Limit total command work to this duration (default 10m; minimum 1s; maximum 30m).
      Type: duration. Required: false. Repeatable: false.
      Default: "10m".
      Constraint: Go duration syntax; 1s <= value <= 30m

Global options:
  -h, --help
      Show help for the resolved command or group and exit 0 without reading state.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -j, --json
      Emit the documented JSON envelope; disable terminal prompts. Help remains plain
      text. Explicit stream and hook exceptions are documented per command.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.
  -v, --version
      Show CQ version and exit 0 without reading state. With --json, use the version
      command envelope.
      Type: boolean. Required: false. Repeatable: false.
      Default: false.
      Constraint: Accept bare flag or =true / =false. Duplicate long/short spellings are
      the same option and are rejected.

Examples:
  cq codex account login
      Store an additional account without activation.
  cq codex account login --activate
      Authenticate and select the account as native client default.
